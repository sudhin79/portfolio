    03:41 · Shift log

    Real systems, and what could have gone wrong at this hour.

    Every project starts with the same question for me: what breaks first, and who finds out?

    Bulk resume parser

    AI · queues · AWS

    A huge batch of PDFs lands at once. The server shrugs.

    The risk
    HR uploads resumes in bulk, the AI parsers pile on, and the whole platform runs out of memory mid-batch.
    What I built
    Containerised batch workers with hard concurrency limits. Failed jobs go to a dead-letter queue and can be re-queued through an admin API, so nothing silently disappears.

    Node.js · React · Docker · AWS EC2 + S3 · Nginx · Let’s Encrypt · CloudWatch

    Enterprise client deployment

    On-prem · RHEL

    No cloud console. No open internet. Ship it anyway.

    The risk
    The client’s environment sits behind a proxy and firewall, with separate web, app and database servers. Source code and packages can’t simply be pulled in.
    What I did
    Deployed the React and Node.js app across their RHEL servers from inside those restrictions, with Nginx routing, HTTPS and domain mapping, and connections to PostgreSQL and Redis.

    RHEL · Nginx · SSL · PostgreSQL · Redis · React/Vite · Node.js

    Observability stack

    Monitoring · AWS

    If it’s down and nobody knows, that’s the real outage.

    The risk
    Users discover problems before the team does. And the build server lived somewhere a metrics scraper couldn’t reach.
    What I built
    Prometheus, Grafana and Alertmanager on EC2, with host and container metrics from Node Exporter and cAdvisor. Jenkins gets scraped safely through a Cloudflare Tunnel.

    Prometheus · Grafana · Alertmanager · Node Exporter · cAdvisor · Cloudflare Tunnel

    AI OCR form processor

    Gemini · GCP

    An AI bill can be an outage too.

    The risk
    Handwritten construction forms arrive as huge PDFs, every page costs AI tokens, and an API key baked into an image is one leak away from disaster.
    What I built
    Multi-stage Docker builds, Nginx upload limits tuned for large files, Gemini keys injected only at runtime, and structured logs tracking token use and processing time.

    Django · React · Docker · Nginx · GCP · Gemini API
